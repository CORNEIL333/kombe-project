01Install on Android

Three steps, two minutes.

  1. Download the file

    Tap “Android — recommended”, then open the downloaded file.

  2. Allow the installation

    If the phone asks, allow “Install unknown apps” for your browser.

  3. Sign in

    Enter your email address and the code you receive. The first code creates your account.

“App not compatible”? Take the “older phones” version, or use the web app.

02iPhone and computer

The web app, no installation.

Open kombe.vercel.app in Safari, Chrome or any recent browser. To find it again like an app, use “Share → Add to Home Screen” (iPhone) or “Install app” (Chrome).
