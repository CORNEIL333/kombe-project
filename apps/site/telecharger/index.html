01Installer sur Android

Trois étapes, deux minutes.

  1. Téléchargez le fichier

    Touchez « Android — recommandé » puis ouvrez le fichier téléchargé.

  2. Autorisez l’installation

    Si le téléphone le demande, autorisez « Installer des applications inconnues » pour votre navigateur.

  3. Connectez-vous

    Saisissez votre adresse e-mail et le code reçu. Le premier code crée votre compte.

« Application non compatible » ? Prenez la version « téléphones anciens », ou utilisez l’application web.

02iPhone et ordinateur

L’application web, sans installation.

Ouvrez kombe.vercel.app dans Safari, Chrome ou tout navigateur récent. Pour la retrouver comme une application, utilisez « Partager → Sur l’écran d’accueil » (iPhone) ou « Installer l’application » (Chrome).
