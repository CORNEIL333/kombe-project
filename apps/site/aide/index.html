01Bien démarrer

Six guides pour commencer.

1

Créer votre compte

Pas de mot de passe à retenir.

  1. Ouvrez kombe.vercel.app ou l’application Android.
  2. Saisissez votre adresse e-mail (ou votre numéro, si le SMS est ouvert).
  3. Recopiez le code à 6 chiffres reçu : votre compte est créé.
  4. Indiquez le nom que les membres de vos groupes connaissent.
2

Créer une tontine

Pour le président ou l’initiateur du groupe.

  1. Depuis « Mes tontines », touchez « Créer une tontine ».
  2. Suivez les étapes : nom, rythme, cotisation, ordre des tours, bureau, règles, relecture.
  3. Partagez ensuite le lien d’invitation (par exemple sur WhatsApp).
3

Rejoindre un groupe

Avec le code ou le lien reçu du bureau.

  1. Touchez « Rejoindre avec un code », ou ouvrez le lien reçu.
  2. Vérifiez le nom du groupe affiché, puis envoyez votre demande.
  3. Le bureau valide votre adhésion : le groupe apparaît alors dans « Mes tontines ».
4

Déclarer une cotisation

Espèces, Orange Money, MTN MoMo, banque…

  1. Ouvrez le groupe, puis « Mes échéances ».
  2. Touchez « Déclarer », choisissez le moyen de paiement et ajoutez la référence si vous en avez une.
  3. Votre déclaration attend la confirmation du trésorier : vous voyez son état à tout moment.
5

Confirmer en tant que trésorier

La confirmation se fait par une autre personne.

  1. Ouvrez l’onglet « Cotisations » du groupe (ou l’Espace bureau sur ordinateur).
  2. Contrôlez chaque déclaration, puis confirmez ou rejetez avec un motif.
  3. Vous ne pouvez jamais confirmer votre propre déclaration.
6

Travailler sans réseau

Pendant une séance sans connexion.

  1. Faites l’appel et saisissez les déclarations normalement.
  2. Elles restent sur le téléphone, marquées « pas encore envoyé ».
  3. Elles partent automatiquement au retour du réseau ; rien n’est présenté comme confirmé avant.
Bientôt disponible

Service après-vente et assistance.

Une assistance directe est en préparation pour répondre aux membres et aux bureaux des groupes. Elle n’est pas encore ouverte : nous préférons l’annoncer clairement plutôt que promettre une réponse que personne ne donnerait.

En attendant, les guides et les questions ci-dessous couvrent l’essentiel, et le bureau de votre groupe reste votre premier interlocuteur.

  • Signalement d’un problème depuis l’application
  • Suivi de votre demande, avec son état
  • Aide aux bureaux pour la mise en place d’un groupe

02Questions fréquentes

Les réponses aux questions courantes.

KÓMBE garde-t-il l’argent du groupe ?

Non. L’argent circule entre membres comme avant (espèces, Mobile Money, virement). KÓMBE tient le registre : qui a déclaré, qui a confirmé, à qui revient le tour.

Je n’ai pas reçu mon code.

Vérifiez l’adresse saisie et le dossier des courriers indésirables, puis demandez un nouveau code. Le code n’est valable que quelques minutes.

Mon adhésion est « en attente ».

C’est normal : un membre du bureau doit valider chaque nouvelle adhésion. Prévenez-le si l’attente se prolonge.

Peut-on corriger une cotisation déjà confirmée ?

Oui, par une correction qui s’ajoute à l’historique. L’écriture d’origine reste visible : rien ne s’efface en silence.

Puis-je utiliser KÓMBE sur iPhone ou sur ordinateur ?

Oui, avec l’application web dans le navigateur. Le bureau dispose aussi de l’Espace bureau, pensé pour le grand écran.

Qui voit mon numéro de téléphone ?

Le bureau de votre groupe. Les autres membres voient votre numéro masqué.
